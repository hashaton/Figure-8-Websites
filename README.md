# Figure 8 Websites

Marketing site for Figure 8 Websites — a company that builds simple, static
$500 websites for small businesses. Plain HTML/CSS/JS, no framework — the
only build step is injecting config values from `.env`.

## Files

- `template.html` — the site source (hero, services, pricing, process, FAQ,
  contact). **Edit this, not `index.html`.**
- `index.html` — generated by `build.js` from `template.html` + `.env`.
  Gitignored; this is what you deploy.
- `styles.css` — all styling
- `script.js` — mobile nav toggle + contact form submission
- `build.js` — reads `.env`, substitutes `__CONTACT_EMAIL__` /
  `__FORM_ACTION__` placeholders in `template.html`, writes `index.html`
- `.env.example` — template for `.env`, safe to commit
- `.env` — your real values; gitignored, never commit it

Note: since this is a static site, `CONTACT_EMAIL` and `FORM_ACTION` aren't
secrets — they end up visible in the HTML sent to every visitor either way.
Keeping them in `.env` is about not hardcoding business-specific config into
the tracked template, not about hiding them from the public.

## Setup

```
cp .env.example .env
```

Edit `.env` with real values, then build:

```
npm run build
```

(`.env` currently has the filler Formspree/email values from `.env.example`
— fine for now, swap in real ones before launch.)

## Before you launch

1. **Contact form** — `FORM_ACTION` in `.env` points at a placeholder
   Formspree URL. Sign up free at https://formspree.io, create a form, and
   put the real endpoint in `.env`. (Any similar form backend — Getform,
   Web3Forms, Netlify Forms — works too; just swap the URL and, if needed,
   `script.js`.)
2. **Contact email** — set `CONTACT_EMAIL` in `.env` to your real inbox.
3. **Copy** — the hero, pricing card, and FAQ in `template.html` use
   placeholder wording; adjust to match your actual turnaround time,
   revision policy, and any add-ons.
4. Run `npm run build` after any `.env` or `template.html` change to
   regenerate `index.html`.

## Running locally

```
npm run build
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploying

`index.html` is a build artifact and isn't committed. Two options:

- **Build then deploy the folder** — run `npm run build` locally, then
  drag-and-drop the folder (with the generated `index.html`) into Netlify,
  or upload it to any static host.
- **Let the host build it** — connect the repo to Netlify/Vercel/Cloudflare
  Pages, set the build command to `node build.js` and the publish directory
  to `.`, and set `CONTACT_EMAIL` / `FORM_ACTION` as environment variables
  in the host's dashboard.
